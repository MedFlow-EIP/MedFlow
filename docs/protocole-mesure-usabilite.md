# MedFlow Protocole de mesure d'usabilité (Mesure de départ)

À faire passer **avant** toute nouvelle modification du produit. Ce protocole doit être réutilisé **à l'identique** en décembre pour la deuxième mesure ne pas le modifier entre les deux.

## Participants
- 5 personnes de la cible (étudiants en médecine)
- **Hors équipe**, n'ayant **jamais utilisé** MedFlow
- Sur leur propre téléphone si possible (sinon, un appareil de test avec l'app installée)

## Déroulé d'une session (~25-30 min)

1. Accueil (2 min) expliquer que c'est le produit qu'on teste, pas la personne ; qu'il n'y a pas de bonne ou mauvaise réponse ; qu'on veut les entendre penser à voix haute.
2. Les 4 tâches, une par une (5-6 min chacune)
3. Questionnaire de satisfaction SUS (5 min) voir document séparé

## Consigne à lire avant de commencer (mot pour mot)

> "Je vais te demander de faire quelques actions dans l'application, comme tu le ferais normalement. Essaie de dire à voix haute ce que tu penses en le faisant pourquoi tu cliques ici, ce que tu t'attends à voir. Je ne vais pas t'aider sauf si tu es vraiment bloqué·e, c'est normal et voulu : je veux voir comment l'app se comporte sans mon intervention."

## Les 4 tâches critiques

Pour chaque tâche : lire la consigne exactement telle qu'écrite, chronométrer dès la fin de la consigne, ne pas aider sauf blocage total > 2 min (le noter comme intervention).

### Tâche 1 Importer un cours et obtenir du contenu généré
**Consigne à lire** : *"Tu as un cours de médecine en PDF sur ton téléphone. Importe-le dans l'app et arrive jusqu'à voir le contenu généré à partir de ce cours."*
*(prévoir un PDF de test à l'avance, l'envoyer au participant avant la session)*

### Tâche 2 Terminer une leçon d'un parcours
**Consigne à lire** : *"Trouve un parcours de révision dans l'app et termine une leçon complète, jusqu'à l'écran de fin."*

### Tâche 3 Se situer par rapport aux autres et ajouter un ami
**Consigne à lire** : *"Trouve où tu peux voir ton classement par rapport aux autres utilisateurs, puis essaie d'ajouter quelqu'un en ami."*

### Tâche 4 Poser une question à l'assistant IA
**Consigne à lire** : *"Pose une question sur un sujet médical à l'assistant IA de l'app et obtiens une réponse."*

## Grille de notation (une par participant)

| Tâche | Réussie sans aide (O/N/Partielle) | Temps (mm:ss) | Nb erreurs / retours en arrière | Nb interventions | Notes qualitatives |
|---|---|---|---|---|---|
| 1. Import PDF | | | | | |
| 2. Terminer une leçon | | | | | |
| 3. Classement + ami | | | | | |
| 4. Question IA | | | | | |

**Définitions** :
- **Réussie sans aide** : la personne arrive au résultat demandé sans intervention. "Partielle" = elle y arrive mais pas de la façon attendue, ou avec beaucoup d'hésitation.
- **Erreur/retour en arrière** : clique sur quelque chose puis fait marche arrière, se trompe d'écran, recommence une action.
- **Intervention** : tu dois donner un indice ou débloquer la personne (bloquée > 2 min).

## Après les 4 tâches
Faire remplir le questionnaire SUS (document séparé), puis poser une dernière question ouverte : *"Comment décrirais-tu cette application à un ami qui ne la connaît pas ?"* (utile aussi pour l'objectif 1 vérifier promesse vs réalité).

## Après les 5 sessions
Compiler les 5 grilles dans un seul tableau (une ligne par participant × tâche), calculer les moyennes de temps et le taux de réussite par tâche. Ça devient la base de la comparaison avec la mesure de décembre.
